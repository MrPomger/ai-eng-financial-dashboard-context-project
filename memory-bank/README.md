# Memory bank del proyecto

Esta carpeta reúne contexto duradero del producto y del código para orientar a contribuidores y agentes. Los documentos describen el estado comprobable del repositorio y separan explícitamente las hipótesis o recomendaciones de las funcionalidades existentes.

## Archivos

- [`product-overview.md`](./product-overview.md): propósito visible, características, personas hipotéticas y criterios propuestos para evaluar el producto.
- [`tech-stack.md`](./tech-stack.md): tecnologías, librerías, dependencias y herramientas declaradas para frontend, backend y desarrollo local.
- [`current-state.md`](./current-state.md): capacidades observables, gaps conocidos y siguientes prioridades sugeridas.
- [`architecture.md`](./architecture.md): estructura de servicios, flujo de datos, contratos y límites arquitectónicos actuales.

Agrega más archivos aquí a medida que el proyecto evolucione.
